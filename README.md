# JARVIS PC V1

Windows desktop assistant starter project.

Features:
- Hindi text commands and voice input (online speech recognition)
- Speech output where a Hindi Windows voice is available
- Open Google, YouTube and ChatGPT in the browser
- GST-inclusive amount calculator for medical-store work

Limitations:
- AI Chat opens ChatGPT in the browser; AI is not embedded in this app.
- Voice recognition needs internet and a working microphone.
- This version does not connect to LocalWell or access stock/sales data.

Build:
1. Open the repository's Actions tab.
2. Select **Build JARVIS Windows EXE**.
3. Click **Run workflow**.
4. When it finishes, open the run and download **JARVIS-PC-Windows-EXE** from Artifacts.
